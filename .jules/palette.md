## 2025-03-09 - Accessible Icon Buttons in Custom Design Systems
**Learning:** When building custom icon buttons (like `PixelIconButton` in Compose) that lack text content, the semantics layer does not automatically infer a content description. This causes screen readers to announce an unlabeled button, hindering accessibility. The issue must be addressed at the component level by explicitly requiring or providing an optional `contentDescription` parameter and applying it via `Modifier.semantics { this.contentDescription = ... }`.
**Action:** Always ensure that custom interactive components, especially icon-only buttons (`PixelIconButton`), provide a mechanism to set `contentDescription` and apply it to their semantic tree, rather than relying solely on default or empty Modifiers.

## 2024-04-29 - Compose Multiplatform A11y & Security Modifiers
**Learning:** In Compose Multiplatform, using `Modifier.clickable(role = Role.Switch)` only announces the component's role to screen readers. To properly announce both the switch role AND its current on/off boolean state, `Modifier.toggleable(value = checked, ...)` must be used. Additionally, for custom icon-only components, `contentDescription` must be applied using `Modifier.semantics { this.contentDescription = ... }` *before* interactivity modifiers. Furthermore, sensitive input fields like passwords should be explicitly configured with `KeyboardOptions(keyboardType = KeyboardType.Password, autoCorrectEnabled = false)` to prevent OS-level dictionary caching and autocomplete leaks.
**Action:** Always prefer `toggleable` over `clickable` for custom switch components. Always expose a `contentDescription` parameter for custom interactive containers or icon-only buttons and apply it via `.semantics`. Explicitly configure `KeyboardOptions` for password fields.
